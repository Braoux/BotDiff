# BotDiff — FAQ / Questions fréquentes

[← Back to BotDiff](../README.md)

## What is BotDiff? / C'est quoi BotDiff ?

BotDiff is a botlane matchup preparation tool for League of Legends. It helps players think through what their **ADC + support** can do against a particular opposing duo.

BotDiff est un outil de préparation des matchups botlane sur League of Legends. Il aide à réfléchir au plan de jeu de ton **ADC + support** face à un duo adverse précis.

## Is BotDiff available? / Est-ce disponible ?

An **alpha version** is accessible at [lanelens.onrender.com](https://lanelens.onrender.com/). Features and reliability may change, and service availability is not guaranteed.

Une **version alpha** est accessible à cette même adresse. Les fonctionnalités et la fiabilité peuvent évoluer.

## Do I need to connect my Riot account? / Faut-il connecter son compte Riot ?

The four-champion selection and analysis experience does not require signing in with a Riot account.

Le parcours de sélection des quatre champions et de demande d'analyse ne nécessite pas de connexion à un compte Riot.

## Can I trust every recommendation? / Peut-on suivre tous les conseils ?

No analysis tool is perfect. Recommendations can be incomplete, outdated or wrong. Check them against the current game patch and adapt your decisions to what happens in the match.

Non. Un conseil peut être incomplet ou incorrect. Vérifie sa pertinence sur le patch actuel et adapte-toi à la situation réelle.

## Is the source code open source? / Le code est-il open source ?

**No.** The BotDiff GitHub repository is a public product presentation, not an open-source release. The engine, application source and internal technical materials are private.

**Non.** Ce dépôt GitHub est une vitrine publique et non une publication du code source. Le moteur, l'application et les documents techniques restent privés.

## Is BotDiff affiliated with Riot Games? / Est-ce un produit Riot ?

No. BotDiff is independent and is not endorsed by Riot Games.

Non. BotDiff est indépendant et n'est pas approuvé ni sponsorisé par Riot Games.

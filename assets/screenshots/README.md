# BotDiff screenshot assets

This directory contains **public product screenshots only**, grouped by the showcased matchup and device. It does not contain BotDiff's application code or any engine data.

## Layout

- `ezreal-xerath-vs-jinx-thresh/desktop/` — desktop captures, 1440 px viewport
- `ezreal-xerath-vs-jinx-thresh/mobile/` — mobile captures, 390 px viewport

Within each device folder, files follow the user journey: `01-selection`, `02-loading`, `03-result`, `04-details`.

For a readable walkthrough and preview, see [the screenshot gallery](../../docs/SCREENSHOTS.md).

Screenshots are illustrative snapshots of the alpha and may change over time.
